# Processamento de Imagens — Aula 3

Notebook de transformações geométricas com operações sobre imagens em escala de cinza.

**Arquivo:** [Proc_Img_Aula_3.ipynb](./Proc_Img_Aula_3.ipynb)

## Conteúdo

- Leitura e conversão da imagem para escala de cinza usando OpenCV
- Translação em dois deslocamentos
- Escalamento
- Espelhamento horizontal e vertical
- Gráficos de resultado preservados no notebook

## Execução

O notebook foi originalmente criado para o Google Colab. Abra o arquivo no Colab, execute a célula de upload e envie a imagem de entrada com o nome **`img.jpg`**, conforme utilizado no código.

Os resultados gráficos salvos estão incluídos no arquivo e podem ser visualizados no GitHub sem executar o notebook. A imagem de entrada `img.jpg` não acompanha este envio; ela é necessária para uma nova execução.

> Organização: este material foi colocado na primeira branch de aula livre após as aulas 1 e 2. O número da aula é provisório, pois o arquivo original não informa essa correspondência.
